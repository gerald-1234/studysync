# Security Policy

## Supported versions

Only the current release on `main` is supported. Fixes are not backported to
older tags.

| Version | Supported |
| ------- | --------- |
| `main`  | Yes       |

## Reporting a vulnerability

Please report vulnerabilities privately rather than opening a public issue.

1. Open <https://github.com/gerald-mathew/studysync/security/advisories/new>.
2. Describe the issue, the steps to reproduce it, and the impact you believe it has.
3. You will get an acknowledgement within a few days.

Please do not test against other people's deployments, and please give a
reasonable amount of time for a fix before disclosing anything publicly.

## Scope

`the StudySync web application` is a personal project, not a hosted service. Reports that only apply
to a deployment someone else operates, rather than to the code in this
repository, may be out of scope.

## Security-relevant dependencies

If a report concerns a transitive dependency, please say which one and how it
is reachable from this code. That is usually enough for it to be actionable.
